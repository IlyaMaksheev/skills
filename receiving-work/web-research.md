# Web research

Follow the loaded `web-research` skill for discovery, source selection, and evidence handling. This module defines the worker-specific authority boundary and terminal report.

# Authority

Research stays within the assignment's permissions and constraints. Return findings and write only authorized artifacts. Apply findings to project state only when the assignment explicitly permits those changes.

# Report contribution

When web findings are part of the expected result, report concise `Research` findings and `Sources` with title/authority and URL. Include `Gaps` only for material unresolved or weakly supported evidence. Summarize rather than reproduce sources.
